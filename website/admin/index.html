100% Dynamic CMS with Standalone Static Engine

Every section of your website is controlled dynamically from this admin dashboard. Whenever you save text or upload image files, the server stores them in the local database (`db.json`) and `/uploads` folder. When you click Generate & Publish, the engine compiles everything into offline static bundles (`js/data.js`), giving you maximum security, zero latency, and 100% offline reliability!
